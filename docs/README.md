## 文档维护约定

- 文档使用简体中文，命令、API、协议字段、状态枚举和文件路径保留原始拼写；
- 用户可见行为变化必须同步更新相关文档；
- 新文档应加入本索引及根 README；
- 示例不得包含真实 Token、私钥或生产证书；
- 发布前应校验本地链接、代码块、命令语义和文档中的版本信息。
