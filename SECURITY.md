# Security policy

MiniTun is pre-release software. Do not deploy the current stage-1 baseline as a tunnel
service; the TLS, authentication, credential-storage, IPC-permission, and resource-limit
phases have not yet been implemented.

Please report vulnerabilities privately through the GitHub repository's security
advisory feature. Do not include tokens, private keys, or other live credentials in an
issue, log, test fixture, or proof of concept.
